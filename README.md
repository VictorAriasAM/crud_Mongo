# CRUD MongoDB

Sistema web desarrollado con PHP y MongoDB para la administración de usuarios mediante operaciones CRUD.

## Tecnologías utilizadas

- PHP
- MongoDB
- Composer
- Bootstrap 5
- HTML5
- CSS3
- JavaScript
- SweetAlert

## Funcionalidades

- Inicio de sesión
- Registro de usuarios
- Alta de registros
- Consulta de registros
- Actualización de registros
- Eliminación de registros
- Conexión a base de datos MongoDB

## Lo que aprendí

Durante este proyecto implementé:

- Integración de MongoDB con PHP.
- Gestión de bases de datos NoSQL.
- Operaciones CRUD.
- Uso de Composer para dependencias.
- Formularios web y validaciones.
- Diseño responsivo con Bootstrap.
